# Bank Marketing Classification

## Project Overview

This project predicts whether a customer will subscribe to a bank term deposit using Machine Learning Classification algorithms.

## Dataset

Bank Marketing Dataset (UCI Machine Learning Repository)

## Algorithms Used

- Logistic Regression
- Decision Tree
- K-Nearest Neighbors
- Naive Bayes
- Support Vector Machine

## Performance Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- AUC
- Matthews Correlation Coefficient (MCC)

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib
- Seaborn

## Run the Application

```bash
streamlit run app.py
```

Upload `test_data.csv` and select a model to evaluate its performance.
